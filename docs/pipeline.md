## 1. 전체 작업 순서

| 순서 | 작업 | GPU 필요 | 어디서 |
|---|---|---|---|
| 1 | 학교 GPU 서버 접속 확인, 환경 파악 (`nvidia-smi`, python 버전, `sinfo`) | - | 서버 |
| 2 | conda 환경 구성 (python 3.10) | 불필요 | 서버 |
| 3 | GPT-SoVITS, CosyVoice2, VITS 3개 설치 | 불필요 (설치만) | 서버 |
| 4 | Zeroth 1,120개 발화 표집 (완료된 스크립트 재실행) | 불필요 | 서버 or 로컬 |
| 5 | **텍스트 치환 (Claude Haiku API, 3,360건)** | **불필요, CPU만** | 어디서든 (노트북 가능) |
| 6 | TTS 합성 (3모델 × 3,360건 = 10,080건) | **필요** | 서버 |
| 7 | Forced alignment + 스플라이싱 (10,080건) | 필요 (GPU 있으면 훨씬 빠름) | 서버 |
| 8 | 자동 품질검사 (WER, 화자 유사도, 경계 불연속) | 필요 (ASR 모델 구동) | 서버 |
| 9 | 사람 검수 (하위 5~10%만 샘플링) | 불필요 | 로컬 (다운로드 후) |
| 10 | 매니페스트 정리, 데이터 품질 점검 | 불필요 | 로컬 or 서버 |

**핵심 포인트**: 5번(텍스트 치환)은 GPU가 필요 없어서, 학교 GPU 서버 접속 전에 미리 끝내둘 수 있음. 그러면 서버 접속하자마자 6번(TTS 합성)으로 바로 넘어가 GPU 사용 시간을 절약함.

## 2. 조작 비율 3구간이 파이프라인에서 갈라지는 지점

3구간(저/중/고)은 오디오를 만든 뒤에 나누는 것이 아니라, **텍스트 치환 단계에서 이미 갈라짐**.

```
원본 발화 1개
    │
    ▼
텍스트 치환 (Haiku API 3회 호출: 2/3/5어절 교체)
    │
    ├── 저(~15%) 텍스트  ──▶ TTS 3모델 각각 ──▶ 정렬·스플라이싱 ──▶ fake 3개
    ├── 중(15~30%) 텍스트 ──▶ TTS 3모델 각각 ──▶ 정렬·스플라이싱 ──▶ fake 3개
    └── 고(30%~) 텍스트  ──▶ TTS 3모델 각각 ──▶ 정렬·스플라이싱 ──▶ fake 3개

발화 1개당: 텍스트 3버전 × TTS 3모델 = fake 파일 9개
```

### 예시 (원본: "...일을 찾아 실천하겠습니다")
- 저(2어절 교체): "...일을 찾아 포기했습니다"
- 중(3어절 교체): "...일을 아예 그만뒀습니다"
- 고(5어절 교체): "...남은 모든 일을 포기하기로 했습니다"

### 치환 프롬프트 예시
```python
prompt = f"다음 문장의 마지막 {n_words}어절을 의미가 달라지도록 자연스럽게 바꿔줘: {원본문장}"
# n_words = 2, 3, 5 로 각각 호출하면 저/중/고 3버전 생성
```

## 3. Claude API 키 발급

1. `console.anthropic.com` 접속 (claude.ai 계정과 별개, 새로 가입 필요)
2. 이메일 또는 Google로 가입, 휴대폰 인증
3. **Settings → Billing** → 신용카드 등록 (결제수단 없으면 키 생성해도 요청 거부됨)
4. **Billing에서 월 지출 한도 설정** (예: $5) — 버그로 무한 호출돼도 그 이상 청구 안 되도록 안전장치
5. **Settings → API Keys → Create Key**, 이름 지정 후 생성
6. `sk-ant-`로 시작하는 키가 단 한 번 표시됨 → 즉시 복사해서 안전하게 보관

### 코드에서 사용
```bash
export ANTHROPIC_API_KEY="sk-ant-여기에-발급받은-키"
```
```python
import anthropic
client = anthropic.Anthropic()  # 환경변수에서 자동으로 키를 읽음
```
키는 절대 코드에 직접 쓰지 않고 환경변수로 관리.

## 4. 비용 계산 (텍스트 치환 단계)

호출 횟수: 원본 발화 1,120개 × 3구간 = **3,360회** (TTS 모델은 같은 치환 텍스트를 재사용하므로 추가 호출 불필요)

문장당 입력 약 150토큰, 출력 약 30토큰 가정:

| 항목 | 토큰 수 | 일반 요금 | Batch API (50% 할인) |
|---|---|---|---|
| 입력 | 504,000 | $0.50 | $0.25 |
| 출력 | 100,800 | $0.50 | $0.25 |
| **합계** | | **약 $1.00** | **약 $0.50** |

모델: Claude Haiku 4.5 ($1/$5 per 1M 토큰, 2026년 8월 기준)
→ 이 규모에서는 실질적으로 무시할 수 있는 비용. Batch API 사용 권장 (실시간 응답이 필요 없는 작업이므로).

## 5. TTS 합성 규모 (참고)

| 구성 | 발화 수 | 시간 |
|---|---|---|
| 원본(genuine) | 1,120개 | 약 2.47시간 |
| GPT-SoVITS × 3구간 | 3,360개 | 약 7.41시간 |
| CosyVoice2 × 3구간 | 3,360개 | 약 7.41시간 |
| VITS × 3구간 | 3,360개 | 약 7.41시간 |
| **총합** | **11,200개** | **약 24.71시간** |

GPU 계산 시간(순차 기준 약 25~30시간)은 배치 처리 시 5~10시간으로 단축 가능. 밤새 돌려놓는 방식 권장. 모델이 하나 늘어난 만큼 3번(TTS 설치) 단계에서 디버깅 시간도 추가로 확보해둘 것.
