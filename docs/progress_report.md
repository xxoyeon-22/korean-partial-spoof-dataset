## 4. 현재까지 도출된 실험 결과

### 4-1. TTS 모델 품질 비교 (단건 실증)
원본 발화 "아울러 미약하게나마 제가 할 수 있는 일을 찾아 실천하겠습니다"(6.95초)를 레퍼런스로 zero-shot 클로닝 수행.

| 모델 | 결과 | 판정 |
|---|---|---|
| **GPT-SoVITS** | 원본 0.55초 어절이 **2.06초**로 합성 (약 4배 늘어짐). 속도·억양 왜곡 심각 | 한국어 품질 열위 |
| **CosyVoice2 (Fun-CosyVoice 3.0)** | 마지막 어절 약 0.48초로 원본(0.55초)과 유사한 속도 유지 | **한국어 품질 우수** |
| VITS | 미검증 | 다음 주 검증 예정 |

→ RQ2(TTS 모델별 탐지 성능 차이)의 사전 근거 확보. 공식 문서상 GPT-SoVITS는 중국어 중심이고 비중국어에서 노이즈 아티팩트가 남는다고 명시되어 있어, 실측 결과와 일치.

### 4-2. 스플라이싱 방법론 검증 결과
| 시도 | 결과 |
|---|---|
| 단어 단위 교체 + 단순 접합 | 뚝 끊기는 소리, 명백한 조작 흔적 → **실패** |
| 샘플레이트 미통일 (16k vs 24/32k) | 합성 구간이 2배속으로 재생 → 원인 규명 후 리샘플링으로 해결 |
| 볼륨 기준을 교체 구간으로 설정 | 문장 끝은 원래 목소리가 잦아드는 구간이라 합성음이 과도하게 작아짐(5~8배) → 문장 전체 발화 기준으로 변경하여 해결 |
| 어림짐작 구간 지정 | 원본 6.95초인데 end=7.0으로 설정 → 뒷부분 유실. forced alignment 도입으로 해결 |
| **절 단위 교체 + forced alignment + 무음 스냅 + 볼륨 정규화 + 크로스페이드** | **청취상 조작 여부 구분 불가 → 성공** |

### 4-3. 텍스트 치환 품질
- 의미 반전 성공률: 육안 검수 기준 양호 (예: "돕는다는 비판도 받았다" → "방해한다는 평가도 받았다")
- 어절 수 일치율: 90.5% (3,041/3,360)
- 불일치 319건 중 대부분이 ±1어절 차이 → forced alignment 후 실측 초 단위로 재분류 예정

### 4-4. 목표 데이터셋 규모 (추정)
| 구성 | 발화 수 | 시간 |
|---|---|---|
| 원본(genuine) | 1,120개 | 약 2.47시간 |
| TTS 3모델 × 3구간 | 10,080개 | 약 22.24시간 |
| **총합** | **11,200개** | **약 24.71시간** |

- 원본 유지 구간: 약 19.25시간 (약 78.0%)
- TTS 변환 구간: 약 5.42시간 (약 22.0%)
- ※ 위 수치는 median 7.93초 기준 **추정치**. 실제 생성 후 매니페스트의 실측값으로 갱신 필요

## 6. 연구 진행을 방해하는 문제

### 6-1. GPU 자원 (최대 병목)
- **문제**: 개인 노트북에 NVIDIA GPU 없음 (Intel Iris Xe 내장그래픽). 로컬 TTS 구동 불가
- **영향**: TTS 합성·forced alignment 등 핵심 작업 전면 대기 상태
- **현재 대응**: Colab 무료 티어(T4)로 단건 검증만 수행
- **해결 예정**: 학교 GPU 서버 확보 (다음 주 예정)

### 6-2. Colab 환경 불안정
- **문제**: 세션 종료 시 설치 환경·생성 파일 전량 소실. Python 3.12 환경에서 GPT-SoVITS 의존성 충돌 다발 (numba 빌드 실패, opencc 빌드 실패, gradio 버전 충돌, numpy 버전 충돌)
- **영향**: 로컬 설치 시도 → Colab 시도 → 커뮤니티 노트북 시도 순으로 반복 실패, 상당한 시간 소모
- **현재 대응**: HuggingFace Space 공식 데모로 우회하여 단건 검증 수행
- **해결 방향**: 학교 서버에서 conda python 3.10 환경 구성 시 대부분 해소 예상

### 6-3. Google Drive 동기화 실패
- **문제**: Colab에서 `to_csv()` 성공 메시지가 출력되었음에도 실제 Drive에 파일이 반영되지 않는 현상 발생. 런타임 재시작 시 파일 유실
- **영향**: `selected_utterances.csv` 재생성 필요했음
- **해결 방향**: 중요 결과물은 `files.download()`로 로컬 직접 저장. **아직 미조치 — 최우선 처리 필요**

### 6-4. TTS 한국어 품질 한계
- **문제**: 주요 오픈소스 TTS가 중국어·영어 중심으로 학습되어 한국어는 부차적 지원. GPT-SoVITS는 어절 길이가 4배 늘어나는 등 왜곡 심각
- **영향**: TTS 모델 선택지 제약. VITS 품질도 미검증 상태로, 품질 미달 시 3모델 비교 설계 수정 필요
- **현재 대응**: CosyVoice2로 우수 품질 확인. VITS 대안(XTTS 등) 사전 조사 필요

### 6-5. 선행 연구와의 방법론 중복 (해소됨, 지속 관찰 필요)
- **문제**: HQ-MPSD(2025.12)가 forced alignment 기반 고품질 스플라이싱이라는 동일 방법론 사용
- **현재 상태**: 원문 확인 결과 언어(유럽 8개어, 한국어 미포함)·TTS 다양성(XTTSv2 단일)·조작 비율 통제(미실시) 세 축 모두에서 차별성 확보 확인
- **잔여 리스크**: 이 분야 데이터셋 논문이 빠르게 출간되고 있어, 논문 작성 시점에 한국어 partial fake 데이터셋이 새로 나올 가능성 존재 → 주기적 문헌 확인 필요
