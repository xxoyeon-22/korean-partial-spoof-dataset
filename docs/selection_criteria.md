## 2. 확정된 발화 선정 기준

> Zeroth-Korean 전체 22,720개 발화(화자 115명) 중 발화 길이가 전체 분포의 p5~p95 구간(5.0~13.3초)에 속하고, 20개 이상의 발화를 보유한 화자(113명, 전체의 98.3%)의 발화만을 대상으로 하였다. 화자 편중을 방지하기 위해 화자당 10개씩 무작위 표집하여 총 1,130개의 원본 발화를 확보하였다. 성별 라벨은 제공되지 않아 화자 단위 균등 배분으로 다양성을 확보하였다.

| 기준 항목 | 값 | 근거 |
|---|---|---|
| 길이 필터 | 5.0 ~ 13.3초 (p5~p95) | Zeroth 실제 분포 (극단값 제외) |
| 어절 수 필터 | 없음 (미적용) | p10이 이미 9어절이라 필터링 효과 없음 |
| 화자 최소 보유 기준 | 20개 이상 | 화자 손실 최소화(115명→113명)하면서 표본 안정성 확보 |
| 화자당 표집 수 | 10개 | 화자 다양성과 목표 규모의 균형 |
| 최종 원본 발화 수 | 1,130개 | 113명 × 10개 |
| 성별 균형 | 미적용 (라벨 없음) | 화자 단위 균등 배분으로 대체 |

## 3. 조작 비율(manipulation ratio) 설계

### 문제였던 점
- 교체 절의 어절 수를 고정(3어절)하면 조작 비율이 발화 길이에 종속됨
  - 예: 3어절 고정 시 mid(15~30%) 구간에 발화의 72%가 쏠리는 교란 발생
  - low 구간은 긴 발화만, high 구간은 짧은 발화만 뽑히는 confound 문제

### 해결 방식
같은 발화 내에서 **교체 어절 수를 조절**하여 세 구간을 생성 (발화 속도 1.72어절/초 기준):

| 교체 어절 수 | 추정 절 길이 | 조작 비율 | 구간 |
|---|---|---|---|
| 2어절 | 약 1.16초 | ~14.7% | low (~15%) |
| 3어절 | 약 1.74초 | ~22.0% | mid (15~30%) |
| 5어절 | 약 2.91초 | ~36.8% | high (30%~) |

→ 발화 길이와 조작 비율 간 교란을 통제하고, **조작 비율을 독립적인 분석 변수**로 사용 가능

### 근거
- PartialSpoof는 공격자가 다양한 방식으로 조작하므로, 데이터베이스는 발화 내 생성 구간이 차지하는 비율이 서로 다른 음성을 포함해야 한다고 명시 (Zhang et al., TASLP 2023 / arXiv:2204.05177)
- NE-PADD는 조작 구간 수(1~10개)로 데이터셋을 나눠 실험한 결과, 구간 수가 많을수록 EER이 낮아져(탐지가 쉬워져) 조작 구간 수가 성능에 유의한 영향을 준다고 보고 (arXiv:2509.03829)
- CFPRF도 발화 내 조작 구간의 길이와 개수가 모델별 탐지 성능에 영향을 준다고 관찰 (ACM MM 2024)

## 4. 화자 분리(speaker-disjoint) 분할

### 근거
- PartialEdit은 ASVspoof2019·PartialSpoof의 화자 설정을 따라, 화자와 발화가 서로 겹치지 않는 훈련(20명)/검증(20명)/평가(68명) 파티션으로 분할 (arXiv:2506.02958)

### 적용
- 표집한 113명 화자를 훈련/검증/평가 세트 간 완전히 겹치지 않도록 분할
- 같은 화자가 훈련과 평가에 동시에 포함되면 탐지 모델이 "조작"이 아니라 "화자"를 학습해 성능이 과대평가되는 것을 방지

---

## 5. 볼륨 정규화

### 근거
- PartialSpoof는 원본과 합성 발화 간 볼륨 차이가 크면 조작 구간 탐지가 지나치게 쉬워져, 모델이 미세한 불일치를 학습하지 못하게 방해한다고 명시
- ITU-T SV56 표준에 따라 **-26 dBov**로 정규화 (Zhang et al., TASLP 2023)

### 적용
- 모든 원본/합성 오디오를 -26 dBov 기준으로 정규화 후 스플라이싱
- (실험 과정에서 RMS 기반 임시 정규화를 사용했으나, 최종 데이터셋 구축 시 표준 방식으로 교체 필요)

## 6. 접합점(splice point) 탐색 방식

### 근거
- PartialSpoof는 아티팩트 없이 이어붙이기 위해 시간영역 상호상관(cross-correlation)으로 최적 접합점을 계산했고, 해당 음성 주변의 무음 영역까지 고려
- VAD는 3종을 돌려 다수결(majority vote) 적용 (Zhang et al., TASLP 2023)

### 적용 (실험 단계 결론)
- 단어 단위 교체는 한국어 연음 특성상 부자연스러움 확인 → **절 단위 교체로 전환**
- Forced alignment(torchaudio MMS_FA)로 정답 텍스트 기반 정확한 단어 위치 탐색
- 무음 구간 중앙(`snap_to_silence`)으로 접합점 보정하여 파형 불연속 최소화
- 향후 상호상관 기반 접합점 탐색으로 고도화 예정

## 7. 진짜/가짜 비율

### 근거
- PartialSpoof 통계: 훈련셋 진짜 2,580 / 가짜 22,800, 평가셋 진짜 7,355 / 가짜 63,882 → 약 1:9 비율

### 적용
- 조작하지 않은 원본 발화도 동일 전처리(정규화)를 거쳐 데이터셋에 포함
- EER 계산을 위해 진짜 샘플 확보 필수 (비율은 목표 규모 확정 후 별도 산정)

## 8. TTS 모델 선정 근거 (실험적으로 확인)

| 모델 | 특성 | 한국어 결과 |
|---|---|---|
| GPT-SoVITS | 중국어 중심 학습, VITS 계열 | 짧은 어절(0.55초)이 2.06초로 늘어지는 등 속도·억양 왜곡 심함 |
| CosyVoice2 (Fun-CosyVoice 3.0) | 9개 언어 명시적 지원(한국어 포함), LLM 기반 zero-shot | 원본과 유사한 속도로 자연스럽게 합성됨 |
| VITS (기본) | End-to-end 고전 구조 | 비교 예정 (baseline 역할) |

- GPT-SoVITS는 중국어에서 가장 성능이 좋고 비중국어에서는 노이즈 아티팩트가 남는다는 것이 공식적으로 언급됨
- CosyVoice2/Fun-CosyVoice 3.0은 모델 카드에 한국어를 9개 주요 지원 언어 중 하나로 명시하고, content consistency·speaker similarity·prosody naturalness에서 SOTA를 달성했다고 명시

## 9. 품질 검증 방식

### 근거
- PartialEdit은 사전학습된 DistillMOS 모델로 각 TTS/편집 모델이 생성한 음성의 자연스러움을 MOS로 추정 (arXiv:2506.02958)

### 적용 계획
- 합성 결과에 대해 (1) ASR 재인식 기반 WER, (2) 화자 임베딩 유사도, (3) 접합 경계 에너지 불연속을 자동 측정
- 하위 품질 샘플만 선별하여 사람이 검수 (전수 검수 대신 샘플링 검수)
